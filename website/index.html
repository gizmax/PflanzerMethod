V korporátu pinká nápad mezi produktem, vývojem, security a legal. Kontext umírá v emailech. Rozhodnutí se dělají na PowerPointu, ne na funkčním kódu. Pflanzer dává programátora do místnosti od minuty 0 — AI vibe-coding tools generují funkční produkční-ready varianty v reálném čase. Winner jde rovnou do produkce, ne jako specka k re-implementaci.

In a corporate, an idea bounces between product, engineering, security and legal. Context dies in email threads. Decisions get made on PowerPoint slides — not on working code. Pflanzer puts the engineer in the room from minute zero — AI vibe-coding tools generate working production-ready variants in real time. The winner ships straight to production, not as a spec for re-implementation.

02 · Specka vs Produkt02 · Spec vs Product

Specka stárne.
Produkt roste.

Specs decay.
Products compound.

Spec-Driven Development (Spec Kit, Kiro, OpenSpec, BMAD) říká: „Nejdřív specka, pak kód." Realita: app → specka → dev → další app, která se liší → pinking. Pflanzer dělá opak — programátor je v room od minuty 0, output je běžící produkt.

Spec-Driven Development (Spec Kit, Kiro, OpenSpec, BMAD) says: „Spec first, code second." Reality: app → spec → dev → a different app → ping-pong. Pflanzer flips it — the engineer is in the room from minute zero, output is a running product.
